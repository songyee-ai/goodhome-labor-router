# 굿홈앤리빙 회사 소개

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 회사명 | 주식회사 굿홈앤리빙 |
| 업종 | 홈패브릭·생활용품 자체 브랜드 기획·판매(커튼, 침구, 쿠션, 러그, 주방·욕실 소품) |
| 판매 채널 | 자사 온라인몰, 직영 매장 4곳, 일부 백화점 팝업 |
| 상시 근로자 | 약 80명(2026년 1월 기준) |
| 본사 | 서울특별시 성동구 |
| 인사·고충 문의 | 경영지원팀 |

## 조직과 인원

| 구분 | 인원 | 구성 | 근무 형태 |
|---|---|---|---|
| 본사 사무직 | 약 40명 | 기획팀, MD팀, 디자인팀, 마케팅팀, 경영지원팀 | 평일 주 5일, 기본 09:00~18:00, 시차출퇴근 가능 |
| 매장 정규직 | 약 24명 | 직영 매장 4곳, 매장별 점장 1명과 매니저·스태프 | 4주 단위 근무표에 따른 오픈조·마감조 교대, 주말 근무와 평일 휴무 |
| 매장 파트타이머 | 약 16명 | 매장별 3~5명 | 근로계약서에 정한 요일·시간 근무. 1주 15시간 이상인 사람과 15시간 미만인 사람이 함께 있음 |

- 회사는 상시 5명 이상을 고용하고 있어 근로기준법이 전부 적용되며, 상시 10명 이상 사업장으로서 취업규칙을 작성·신고하고 있습니다.
- 직원 구분과 1주 15시간 기준의 정확한 정의는 「취업규칙」 제1장을 따릅니다.

## 인사·고충 문의 창구

인사·급여·휴가·복리후생·고충 문의는 모두 **경영지원팀**에서 받습니다. 매장 직원도 점장을 거치지 않고 경영지원팀에 직접 문의할 수 있습니다.

| 문의 | 연락처 |
|---|---|
| 인사·근로계약·휴가 | 내선 2041 / hr@goodhome-living.example |
| 급여·퇴직금 | 내선 2042 / payroll@goodhome-living.example |
| 고충 상담·괴롭힘·성희롱 신고 | 내선 2043 / talk@goodhome-living.example |
| 익명 신고 | 사내 인사포털의 "마음함" 게시판 |

- 문의 가능 시간: 평일 09:00~18:00(점심시간 12:00~13:00 제외)
- 고충 상담과 신고 절차는 「취업규칙」 제10장을 따릅니다.
