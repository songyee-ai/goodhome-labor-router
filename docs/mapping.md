# 카테고리 ↔ 근거 매핑표

카테고리마다 프롬프트에 넣는 근거는 이 표의 범위뿐이다. 프로그램은 같은 내용을 `data/category_map.json`에서 읽는다.

- 사규: `docs/company/취업규칙.md`, `docs/company/복리후생규정.md` (실존 회사와 무관한 가상 회사 굿홈앤리빙의 규정)
- 법령: `docs/law/*.md` (국가법령정보센터 현행 조문 원문, 조문 목록은 `docs/law/index.md`)
- 취업규칙 제3조(직원의 구분)·제4조(1주 15시간 기준)는 모든 카테고리에 붙인다. 주 15시간 미만 파트타이머의 적용 제외가 카테고리마다 답을 바꾸기 때문이다.

## 근거에 일부러 넣지 않은 것

- 정부가 주는 육아휴직 급여·출산전후휴가 급여 액수(고용보험법): 사내 복직 지원금만 답하고 나머지는 담당 기관으로 안내하는 "부분 넘기기" 문항용
- 연말정산, 4대보험, 실업급여: 범위 밖 문항용
- 2027년 적용 최저임금: "올해 최저임금" 질문에서 다른 해 금액을 말하는지 검사하는 문항용
- 근로기준법 시행령 별표 1·2: 원문이 첨부 파일이라 텍스트로 받지 못함
